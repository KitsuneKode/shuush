Why We Built Shuush: An Open-Source Local Superwhisper & Wispr Flow Alternative for Linux

TL;DR · Direct Answer & Verified Benchmarks
  • What Shuush is: A free, MIT-licensed desktop layer & native GTK4 Studio built on top of stock voxtype for Linux/Wayland (Hyprland, Omarchy, Sway, Niri).
  • Why not cloud dictation? Wispr Flow costs $15/month and skips Linux; Omarchy's default Superwhisper cloud tier caps free usage at 10,000 words/month. We already dictated 19,498 words across 333 real takes (~8.1 hours saved).
  • Measured performance (RTX 4050 Laptop 6 GB VRAM · i5-13450HX): Parakeet fp16 uses ~2.3 GB VRAM locally; end-to-end cleanup runs at 516 ms P50 / 1,060 ms P90 with 98.8% reliability (or 24 ms when text is already clean).
  • Key innovations: 5-source AT-SPI context, deterministic anti-paraphrase span gating, phonetic self-learning with dictionary-poisoning guards, and 1-click Air-Gapped Ollama mode.

1. The Gap on Linux Voice Dictation

Voice dictation finally got genuinely good for software engineers in 2025–2026 — not because speech-to-text got slightly more accurate, but because tools like Wispr Flow and Superwhisper paired speech recognition with active window context and fast LLM cleanup.

On Linux, however, developers hit an awkward split: either accept closed-source apps with monthly word limits (like Superwhisper's 10,000 free words/30 days on Omarchy), or wire up bare Whisper scripts that spell Waybar as "webar", Next.js as "next year", and voxtype_pp_gate as "box type pp gate".

Rather than reinventing a Rust audio/inference daemon from scratch, we built Shuush cleanly on top of Peter Jackson's MIT-licensed voxtype. Keeping voxtype untouched means Shuush works immediately on top of stock voxtype-bin across NVIDIA CUDA, AMD ROCm/Vulkan, Intel Vulkan, and CPU-only laptops.

2. Stealing the Best Ideas from Superwhisper — Locally and Unlimited

Superwhisper's signature feature ("Super Mode") works because the cleanup model sees what you're looking at. We ported that idea to Wayland using 5 bounded, secret-redacted context sources captured right when you press your dictation hotkey:

  1. Active application & window title (Hyprland, Niri, Sway) to pick the right profile (terminal, chat, or default) and refocus the original window if you switch away while polishing.
  2. AT-SPI visible <screen> & focused <draft> (voxtype_screen_ctx.py, hard-capped at 250ms) so terms visible in your editor or browser ground symbol spelling — and real password fields trigger an instant privacy bypass.
  3. Highlighted <selection> captured in the background on normal dictation too, so saying "fix this error in that hook" resolves exact identifiers.
  4. Fresh <clipboard> (≤15-second window) tracked by SHA-256 hash + timestamp, so a stack trace you copied 5 seconds ago improves accuracy while a 2-hour-old clipboard never pollutes your prompt.
  5. Current date anchor (<now>) so relative dates stay grounded.

3. Why Raw LLM Cleanup Fails — and How the Anti-Paraphrase Span Gate Solves It

Every engineer who wires an LLM onto Whisper discovers the same failure mode within an hour: the model gets helpful and rewrites your tone, drops technical flags, or answers dictated questions instead of transcribing them.

Shuush solves this with a deterministic verification layer, voxtype_pp_gate.py. Before any LLM output is typed, the span gate aligns every word back against the raw ASR transcript. Rewrites are only accepted if they are filler removals, punctuation/casing fixes, or phonetically close to a term grounded in your vocabulary.txt, corrections.tsv, or live 5-source screen context. When the recognizer output is already clean, Shuush skips the LLM completely in 24 ms.

4. Self-Learning That Never Poisons Your Dictionary

Naive auto-learning learns disastrous rules like hosts → hooks or things → tasks the first time an LLM guesses from context — corrupting future dictations forever. Shuush's voxtype_learn.py enforces four strict guards:

  • Ordinary English blocklist (probing system wordlists across Arch, Debian, Ubuntu, and Fedora + a built-in fallback wordlist).
  • Phonetic & spoken-digit folding so ASR splits like t three → T3 and cube ctl → kubectl are matched cleanly when grounded.
  • Casing-preserving swap logging so Next.js, Waybar, and T3 retain exact capitalization signals.
  • Permanent reject blocklist with Undo plus automatic sync into voxtype's Layer-1 config.toml [text] replacements and vocabulary.txt.

6. Install Shuush on Any Wayland Setup

Shuush installs cleanly on top of stock voxtype-bin with zero fork replacement, and includes first-party integration for the kuwai Hyprland rice:

yay -S voxtype-bin wtype wl-clipboard jq python-gobject libadwaita gtk4 at-spi2-core
voxtype setup
git clone https://github.com/KitsuneKode/shuush.git && cd shuush
./install.sh --wire-config
shuush doctor && shuush studio

Open Settings (Alt+6) to toggle Air-gapped offline mode (Ollama only) or add cloud API keys (saved locally with chmod 600). Everything is MIT-licensed at github.com/KitsuneKode/shuush.
